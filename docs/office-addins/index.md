# Office Add-ins

Plexus provides add-ins for Microsoft Outlook and Microsoft Word, allowing you to access the full Plexus Gateway application directly from within your Office apps.

## Installation

Download the manifest file for the add-in you want to install:

- [Outlook Add-in Manifest](manifest-plexus-outlook.xml)
- [Word Add-in Manifest](manifest-plexus-word.xml)

### Sideloading the add-in

To install a Plexus add-in using the manifest file, follow the Microsoft documentation for sideloading:

- **Outlook**: [Sideload Outlook add-ins for testing](https://learn.microsoft.com/en-us/office/dev/add-ins/outlook/sideload-outlook-add-ins-for-testing)
- **Word**: [Sideload Office add-ins for testing](https://learn.microsoft.com/en-us/office/dev/add-ins/testing/sideload-office-add-ins-for-testing)

### Centralized deployment

For organisation-wide deployment, your Microsoft 365 administrator can deploy the add-in using [centralized deployment](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-deployment-of-add-ins).

## Features

For more details on add-in features, see the [Plexus Help Centre](https://help.plexus.co).
